
# VMS – Trike vs Team Cera

Official VMS player performance rating form.

## Purpose
This project provides a rating form for individual Ceratosaurus players participating in Trike vs Team Cera fights.

## Rating Categories
- Survival
- Damage Taken
- Damage Dealt
- Solo Fight
- Combat Performance

## Difficulty Multipliers
- Easy – Prime Ceratosaurus: ×1.2
- Hard – Adult Ceratosaurus: ×1.5

## Features
- Automatic score calculation
- Individual player evaluation
- Mobile-friendly layout
- Automatic reset after 30 seconds of inactivity
- Screenshot-ready result sheet
